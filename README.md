# ЕдаРядом — учебный проект Django

Адаптивный учебный сервис доставки еды из ресторанов. Интерфейс вдохновлён присланным прототипом Figma: светлый фон, синие акценты, карточная сетка каталога, крупная шапка, меню, профиль и формы.

## Что реализовано

- Главная, каталог ресторанов, страница ресторана с меню, регистрация, вход, личный кабинет, корзина, оформление заказа, о проекте и результаты поиска.
- Семантические элементы `header`, `nav`, `main`, `section`, `article`, `footer`; по одному `h1` на страницу; изображения-иллюстрации оформлены декоративно и скрыты от скринридера, содержательные ссылки имеют текст.
- Именованные маршруты Django; ссылки в шаблонах используют `{% url %}`.
- Модели: DeliveryZone, Category, Restaurant, Dish, Order, OrderItem, Courier, Delivery.
- Поиск, фильтрация по категории, сортировка, пагинация по 20 элементов.
- Сессионная корзина; добавление блюда через `fetch` к JSON-представлению без перезагрузки; индикатор загрузки, уведомление и обновление счётчика.
- Корзина ограничена одним рестораном. При оформлении проверяется минимальная сумма и зона доставки. Стоимость доставки берётся из зоны. Время приготовления заказа — максимум среди выбранных блюд.
- Django Forms, CSRF, серверная проверка телефона, отображение ошибок и сохранение введённых значений средствами Django, сообщения и redirect после успеха.
- JS-проверка обязательных полей, email, телефона; бургер-меню.
- CSS-переменные, Flexbox и адаптивные сетки.

## Запуск локально

Нужен Python 3.10+.
```base
python -m venv venv
# Windows:
venv\\Scripts\\activate
# macOS/Linux:
source venv/bin/activate
pip install -r requirements.txt
python manage.py makemigrations delivery
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ . Интернет для работы Django и базы не нужен. Google Fonts подключён как необязательное улучшение: без интернета будет системный шрифт.

## Структура

- `config/` — настройки и корневые маршруты проекта.
- `delivery/models.py` — сущности базы данных.
- `delivery/views.py` — страницы, поиск, корзина и JSON endpoint.
- `delivery/forms.py` — формы регистрации и оформления заказа.
- `delivery/urls.py` — именованные маршруты приложения.
- `delivery/management/commands/seed_demo.py` — демонстрационные данные.
- `templates/delivery/` — HTML-шаблоны.
- `static/css/style.css` — стили и адаптивность.
- `static/js/main.js` — бургер, клиентская проверка и fetch.
- `media/` — загружаемые изображения (создаётся автоматически).

## Админка и данные

Перейдите на `/admin/`, войдите суперпользователем и редактируйте рестораны, категории, блюда, зоны и заказы. Демонстрационные карточки создаются командой `seed_demo` из базы, а не прописаны в шаблонах. Для реальной сдачи замените демонстрационные названия/данные на свои подтверждённые данные и добавьте фотографии оптимизированного размера.
